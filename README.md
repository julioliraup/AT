# Antiphishing Panel

Welcome to the **Antiphishing Panel**, the web dashboard for the [julioliraup/antiphishing](https://github.com/julioliraup/Antiphishing) project. This repository (`AT`) hosts the frontend interface and automated scripts used to visualize, search, and manage our frequently updated Suricata rules against phishing threat vectors.

## Features

- **Dynamic Search**: Easily query threat intelligence by URL or Suricata SID.
- **Threat Intelligence**: Enriched with external APIs (such as AlienVault OTX) for detailed geolocation, file hashes, and safe browsing hits.
- **Visualizer**: An interactive, cyberpunk-themed interface providing real-time statistics and insights into our dataset.
- **Automated Deployments**: Rules and data are processed and deployed automatically to GitHub Pages.
